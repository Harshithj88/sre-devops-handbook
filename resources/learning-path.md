# SRE / DevOps Learning Path

## Beginner

### Fundamentals

- **Linux basics** — command line, file system, permissions, processes, networking
- **Networking** — TCP/IP, DNS, HTTP/HTTPS, load balancing, firewalls
- **Version control** — Git branching, merging, pull requests, code review workflow
- **Scripting** — Bash or PowerShell for task automation

### Recommended Resources

- [Linux Journey](https://linuxjourney.com/)
- [Git Pro Book](https://git-scm.com/book/en/v2)
- [PowerShell Documentation](https://learn.microsoft.com/en-us/powershell/)

---

## Intermediate

### Containers and Orchestration

- **Docker** — images, containers, Dockerfile, networking, volumes
- **Kubernetes** — pods, deployments, services, ingress, ConfigMaps, Secrets
- **Helm** — chart management, templating, releases

### CI/CD

- **GitHub Actions** — workflows, jobs, steps, environments, secrets
- **Azure DevOps Pipelines** — YAML pipelines, stages, approvals
- **Build strategies** — artifact versioning, environment promotion

### Infrastructure as Code

- **Azure Bicep** — modules, parameters, outputs, deployment scopes
- **Terraform** — providers, resources, state management, modules

### Recommended Resources

- [Docker Getting Started](https://docs.docker.com/get-started/)
- [Kubernetes Documentation](https://kubernetes.io/docs/)
- [GitHub Actions Documentation](https://docs.github.com/en/actions)
- [Azure Bicep Documentation](https://learn.microsoft.com/en-us/azure/azure-resource-manager/bicep/)

---

## Advanced

### Site Reliability Engineering

- **SLOs, SLIs, Error Budgets** — defining and measuring reliability targets
- **Incident management** — detection, response, mitigation, postmortems
- **Change management** — risk assessment, approval workflows, rollback strategies
- **Capacity planning** — resource forecasting, load testing, autoscaling
- **Toil reduction** — identifying and automating repetitive operational work

### Observability

- **Prometheus** — metrics collection, PromQL, alerting rules
- **Grafana** — dashboard creation, alerting, data sources
- **OpenTelemetry** — instrumentation, collectors, exporters
- **Distributed tracing** — understanding request flow across services
- **Log aggregation** — structured logging, centralized log management

### Cloud Platform (Azure)

- **AKS** — cluster management, networking, security, monitoring
- **Azure Monitor** — metrics, logs, alerts, workbooks
- **Azure Key Vault** — secrets management, certificate lifecycle
- **Azure Front Door** — global load balancing, WAF, caching
- **Azure Policy** — governance, compliance, enforcement

### Recommended Resources

- [Google SRE Book](https://sre.google/sre-book/table-of-contents/)
- [Google SRE Workbook](https://sre.google/workbook/table-of-contents/)
- [Prometheus Documentation](https://prometheus.io/docs/)
- [OpenTelemetry Documentation](https://opentelemetry.io/docs/)
