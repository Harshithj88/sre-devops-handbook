# SRE Readiness Checklist

## Service Ownership

- [ ] Service owner is clearly defined
- [ ] Engineering team responsible for service is documented
- [ ] Escalation contacts are available
- [ ] On-call rotation is defined
- [ ] Support hours are documented

## Architecture

- [ ] Architecture diagram exists
- [ ] Upstream dependencies are documented
- [ ] Downstream dependencies are documented
- [ ] External integrations are documented
- [ ] Data flow is documented
- [ ] Failure points are identified

## Reliability

- [ ] SLOs are defined
- [ ] SLIs are measurable
- [ ] Error budget is defined
- [ ] Availability target is documented
- [ ] Latency target is documented
- [ ] Recovery Time Objective is defined
- [ ] Recovery Point Objective is defined

## Observability

- [ ] Metrics are available
- [ ] Logs are centralized
- [ ] Traces are available where applicable
- [ ] Dashboards exist
- [ ] Alerts are configured
- [ ] Alerts are actionable
- [ ] Alert ownership is defined

## Deployment

- [ ] CI/CD pipeline exists
- [ ] Rollback process is documented
- [ ] Deployment approvals are documented
- [ ] Release notes are generated
- [ ] Change management process is followed
- [ ] Production deployment window is defined

## Security

- [ ] Secrets are stored securely
- [ ] Least privilege access is followed
- [ ] Vulnerability scanning is enabled
- [ ] Container image scanning is enabled
- [ ] Audit logging is enabled
- [ ] Access review process exists

## Operations

- [ ] Runbooks exist
- [ ] Incident response process is documented
- [ ] Postmortem template exists
- [ ] Known issues are documented
- [ ] Operational dashboards are reviewed regularly
